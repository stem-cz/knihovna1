Ovsědčený postu při intalaci
1. Stáhnout si knihovnu1 k sobě na lokální disk (buď přes bash git clone https://github.com/stem-cz/knihovna1.git v terminálu; nebo clone přes deskopovou aplikaci Github)
2. instaluješ library devtools install.packages("devtools")
3. Zaktualizuješ Javu na nejnovější verz
4. v konzoli spustíš příkaz devtools::install_github("CestaKeKnihovně/knihovna1")
5. Pokud se vše povedy půjde klasicky načíst library(knihovna1)
